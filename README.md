# 推しログ (OshiLog)

推し活の「お金」「当落戦績」「スケジュール」をブラウザ上で一元管理できる、ローカル完結型のシングルページアプリケーション（SPA）です。
主にスマホ利用を志向していますが、PCでも閲覧・利用ともに可能です。

URL：[stellular-parfait-11a86c.netlify.app](https://stellular-parfait-11a86c.netlify.app/)

## 🎯 概要・コンセプト
チケットの当落結果から遠征費の細かな内訳、グッズの欲しいものリストまで、推し活に伴うあらゆる情報を整理するために開発されました。
すべてのデータはお使いのブラウザ（`localStorage`）にのみ保存されるため、プライバシーが守られ、サーバーやデータベースの構築も一切不要です。HTMLファイルをブラウザで開くだけですぐに使い始めることができます。

## ✨ 主な機能
* **活動記録と支出管理（4分割）**
  * 活動ごとに「チケット代等」「ホテル代」「交通費」「その他」の4項目で支出を細かく記録。
  * 「未来の予定（未確定）」と「実績（確定済）」のステータス管理。
* **当落管理ダッシュボード**
  * 公演ごとの当落ステータス（結果待ち / 当選 / 落選）管理。
  * 期間（年別）・活動種類・場所によるフィルタリングと、「〇戦〇勝（勝率〇％）」の自動計算。
  * 当選データを1クリックで「活動記録（予定）」へ自動引き継ぎ。
  * 連続入力に特化した「ステータスリセット型のコピー（複製）」機能。
* **推し活統計機能**
  * 月別の支出推移（棒グラフ）と、活動種類別の支出割合（円グラフ）の可視化。
  * 生涯の総実績回数、総支出額の集計。
* **安心のデータ管理**
  * 容量節約のための「アイコン画像の自動圧縮・透過維持クロップ機能（WebP変換）」。
  * JSON形式での全データのエクスポート（バックアップ）およびインポート（復元）機能。

## 🚀 使い方
1. 本リポジトリの `oshilog_v5.html`（最新版）をダウンロードします。
2. PCやスマートフォンのブラウザ（Chrome, Safari, Edgeなど）でファイルを開きます。
3. 初回起動時にサンプルデータが作成されます。「設定」タブから推しの情報を編集して利用を開始してください。

## ⚠️ 今後の課題・検討事項 (Issues)

本アプリは手軽さと安全性を優先し `localStorage`（容量上限: 約5MB）を採用していますが、長期間の運用において以下の課題とジレンマを抱えています。

**1. データ容量の肥大化とシステム移行（IndexedDB）の壁**
画像の自動圧縮によりテキストのみであれば数年単位で運用可能ですが、最終的な容量限界に達した際、`IndexedDB` へのシステム移行が選択肢に挙がります。しかし、IndexedDBは「OSやブラウザの都合（端末のストレージ不足など）で、ユーザーの許可なく勝手にデータが消去される（Eviction）」という致命的なリスクがあり、安全なローカル管理というコンセプトと相反する懸念があります。

**2. アーカイブ運用における「生涯戦績」の喪失感**
容量限界の回避策として、「年次や区切りのタイミングでJSONをエクスポートし、アプリ側のデータをリセットする（アーカイブ運用）」が現実的です。
しかし、この運用を行うと、本アプリの醍醐味であるダッシュボードの「累計総支出額」や「生涯の当落勝率」がゼロにリセットされてしまうため、推し活のモチベーションや「歴史の積み重ね」を視覚的に楽しめなくなるデメリットが生じます。

**3. マスタデータと履歴データの分離（次期アップデート候補）**
アーカイブ運用を前提とした場合、現状の「全データクリア機能」では、推しのプロフィールやリンク集、未購入のウィッシュリストといった【マスタデータ】まで消去されてしまいます。
今後の改修として、「活動履歴と当落データのみを消去し、基本設定は引き継ぐ（部分クリア機能）」の実装が求められます。
